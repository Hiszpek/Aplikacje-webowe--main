
# 0.6: New note in Single Page App

```mermaid
sequenceDiagram
    participant browser
    participant server

    Note over browser: User writes a note and clicks Save

    Note over browser: JavaScript prevents the default form submission
    Note over browser: Browser adds the note to the local list and redraws the notes

    browser->>server: POST /new_note_spa (JSON data)
    Note right of browser: Data contains content and date
    Note right of server: Server saves the note
    server-->>browser: HTTP 201 Created (JSON response)

    Note over browser: The page is not reloaded
```
